Why this tool

UVVM provides the verification building blocks; a new project still begins with repetitive wiring and decisions about where each VVC belongs.

TB Scaffold turns that first pass into a local visual layout and readable VHDL pair, while keeping the DUT map, widths, and test intent firmly in your hands.
